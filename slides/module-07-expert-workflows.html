The /parse-resume Skill

You convert a résumé into a valid JSON Resume file.

## Input:  $ARGUMENTS  (.pdf/.docx/.md/.txt)
## Task
1. Read the résumé.
2. Extract into JSON Resume: basics, work, education, skills.
3. Write 2–4 achievement highlights per role (verb + number).
4. Never invent facts — omit missing fields.

## Output Contract
Output ONLY valid JSON. No preamble, no fences.
/parse-resume ~/Documents/my-resume.pdf > resume.json

Output contract = a skill a program can consume.

app.js — Fetch and Render

const data = await (await fetch("resume.json")).json();

document.getElementById("work-list").innerHTML =
  (data.work || []).map(w => `
    <article class="entry">
      <h3>${w.position} · ${w.name}</h3>
      <span>${w.startDate} – ${w.endDate || "Present"}</span>
      <ul>${(w.highlights||[]).map(h=>`<li>${h}</li>`).join("")}</ul>
    </article>`).join("");

Preview: python3 -m http.server 8000

Change resume.json → reload → done. No HTML touched.

Two Mechanisms, Two Purposes

A. Sign in with LinkedIn (OIDC) — live, but limited

Returns ONLY: sub · name · picture · email · locale
NO positions, NO job history.

B. Data export — how experience actually gets in

Settings → Get a copy of your data
→ Positions.csv, Education.csv, Skills.csv
→ /import-linkedin → resume.json
⚠️ Token exchange needs a secret → a static site needs a tiny
serverless function. Sign-in personalizes; export supplies data.

Create a Repo & Ship to Pages

1. Make it a repo (local):

cd portfolio && git init && git add .
git commit -m "Portfolio"

2. Create the repo on GitHub — [github.com/new](https://github.com/new)

→ name portfolio · Public · don't add README, then:

git remote add origin https://github.com/YOU/portfolio.git
git branch -M main && git push -u origin main

(auth: use a Personal Access Token, or gh / GitHub Desktop)

3. Enable Pages: Settings → Pages → branch main / root

→ live at https://YOU.github.io/portfolio/

Update later: edit resume.json → git push → auto-redeploys.
